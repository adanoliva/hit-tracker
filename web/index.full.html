Especificaciones

Hardware

  • Microcontrolador: ESP32-32D
  • Sensor: GY-521 (MPU-6050)
  • Frecuencia: 100Hz
  • Rango: ±16g aceleración
  • Conexión: Bluetooth 4.2 BLE
  • Alimentación: USB 5V

Métricas

  • Power: Intensidad golpe (0-100)
  • Valid Hit: Golpes > 80% power max
  • HPM: Golpes por minuto
  • Accuracy: ±2% en magnitud
  • Latency: <50ms procesamiento
  • Storage: Ilimitado (archivos JSON)

Software

  • Desktop: Electron 27+ / React 18+
  • Mobile: React Native + Expo
  • Lenguaje: TypeScript 5+
  • Estado: Zustand 4+
  • Gráficos: Recharts 2+
  • Licencia: MIT

Crea el tuyo

HitTracker es un proyecto completamente abierto, publicado bajo licencia GPL v3. Esto significa que el código fuente de la aplicación — tanto desktop como mobile — es libre de usar, estudiar, modificar y distribuir. Si quieres adaptarlo a tu saco, a tu gimnasio o a tu forma de entrenar, tienes todo el derecho a hacerlo. Eso sí: cualquier versión modificada que distribuyas debe publicarse también bajo GPL v3, con el código fuente disponible y reconociendo el proyecto original. La libertad se comparte, no se cierra.

Lo mismo aplica al hardware. El esquema del sensor está basado en componentes accesibles: un ESP32 y un módulo GY-521 (MPU-6050), disponibles por menos de 10€. Con un poco de soldadura y el firmware incluido en el repositorio, puedes construir tu propio sensor desde cero y conectarlo a la app en minutos. ¿Te animas a diseñar una carcasa molona?

El repositorio incluye el código del firmware, la aplicación desktop, la app mobile y la documentación necesaria para ponerte en marcha. Las contribuciones son bienvenidas.

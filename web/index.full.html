Cómo Funciona

1

Conecta el Sensor

Programa el ESP32 con el firmware. La app detecta automáticamente el dispositivo via Bluetooth.

→
2

Calibra

Realiza 3 series de golpes (ligero, normal, fuerte). El sistema aprende tu patrón.

→
3

Entrena

Inicia sesión. El sensor captura datos a 100Hz. App procesa en tiempo real.

→
4

Analiza

Al terminar, resultados detallados. Power máximo, RPM, valid hits, progreso histórico.

Hardware: ESP32 + MPU-6050
App: Electron + React
Comunicación: Bluetooth BLE
Frecuencia: 100Hz / 10ms

Especificaciones

Hardware

  • Microcontrolador: ESP32-32D
  • Sensor: GY-521 (MPU-6050)
  • Frecuencia: 100Hz
  • Rango: ±16g aceleración
  • Conexión: Bluetooth 4.2 BLE
  • Alimentación: USB 5V

Métricas

  • Power: Intensidad golpe (0-100)
  • Valid Hit: Golpes > 80% power max
  • RPM: Golpes por minuto
  • Accuracy: ±2% en magnitud
  • Latency: <50ms procesamiento
  • Storage: Ilimitado (archivos JSON)

Software

  • Framework: Electron 27+
  • Frontend: React 18+
  • Lenguaje: TypeScript 5+
  • Estado: Zustand 4+
  • Gráficos: Recharts 2+
  • Licencia: MIT

Requisitos

  • OS: Windows, macOS, Linux
  • RAM: 512MB mínimo
  • Node.js: 16+ (desarrollo)
  • Bluetooth: Necesario
  • Espacio: ~200MB
  • Setup: 10 minutos

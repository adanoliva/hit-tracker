## Descripción

Asistente paso a paso que guía al usuario para calibrar un perfil específico para el sensor conectado. El usuario da 5 golpes en cada una de las 3 intensidades (suave, normal, fuerte). El sistema calcula automáticamente `threshold` y `sensitivity` óptimos y guarda un `DeviceCalibration` en el perfil. Accesible desde el badge "⚠ Calibrar ahora" de la pantalla Sesión Activa y desde la pantalla de Perfiles.

## Criterios de aceptación

- [ ] El asistente es accesible desde: (a) badge "Calibrar ahora" en Sesión Activa, (b) botón "Calibrar para [sensor]" en la pantalla de detalle de un perfil
- [ ] El asistente requiere un sensor conectado para funcionar; si no hay sensor activo, muestra error
- [ ] El asistente tiene 4 pasos: Introducción → Golpes suaves → Golpes normales → Golpes fuertes → Resultado
- [ ] Cada paso de golpes solicita exactamente 5 impactos y muestra el progreso (1/5, 2/5, ... 5/5)
- [ ] Cada golpe detectado se muestra visualmente con feedback inmediato (número + barra de magnitud)
- [ ] El usuario puede repetir una serie completa (botón "Repetir esta serie") antes de continuar
- [ ] El usuario puede cancelar el asistente en cualquier paso; la calibración anterior (si existía) no se modifica
- [ ] Tras los 3 series de golpes, el sistema calcula y muestra un preview de threshold y sensitivity calculados
- [ ] El usuario puede aceptar o repetir toda la calibración desde el preview
- [ ] Al aceptar, se guarda un `DeviceCalibration` en el perfil activo para el sensor activo
- [ ] Si ya existía una `DeviceCalibration` para ese par, se sobreescribe con confirmación previa
- [ ] Tras guardar, la pantalla Sesión Activa muestra "✓ Calibrado para este sensor"

### Lógica de negocio

#### Paso Introducción
- Muestra el sensor activo y el perfil que se va a calibrar
- Explica brevemente el proceso: "Darás 5 golpes suaves, 5 normales y 5 fuertes para ajustar la sensibilidad de detección"
- Botón "Empezar calibración"

#### Pasos de golpes (light / normal / heavy)

Para cada serie, el asistente:
1. Muestra instrucción: "Golpea SUAVE 5 veces" / "Golpea NORMAL 5 veces" / "Golpea FUERTE 5 veces"
2. Escucha todos los impactos del sensor (threshold=0 durante la calibración para capturar cualquier golpe)
3. Al detectar un impacto, añade `impact.magnitude` a `series.hits`
4. Muestra progreso y feedback visual (lista de barras con la magnitud de cada golpe)
5. Al llegar a 5 hits: muestra resumen de la serie + botones "Repetir" / "Continuar"
   - "Repetir": vacía `series.hits` y vuelve a escuchar
   - "Continuar": avanza al siguiente paso

**Threshold durante calibración**: usar `threshold = 0` para capturar todos los impactos, ya que aún no tenemos un threshold calculado.

**Anti-rebote**: usar cooldown de 300ms entre golpes (igual que en entrenamiento normal) para no registrar dobles.

#### Paso Resultado — cálculo

```ts
const result = calibrationService.buildDeviceCalibration(
  sessionStore.activeSession.deviceMac,
  {
    light: series.light.hits,
    normal: series.normal.hits,
    heavy: series.heavy.hits,
  }
)
```

Preview mostrado al usuario:
```
Calibración calculada para [nombre sensor]:

  Umbral de detección:  {result.threshold}
  Sensibilidad:         {result.sensitivity}

  Rango estimado: suave ≈ {lightAvg} · normal ≈ {normalAvg} · fuerte ≈ {heavyAvg}

  [ Aceptar y guardar ]    [ Repetir calibración ]
```

Donde `lightAvg = average(series.light.hits)`, etc.

#### Guardar calibración
```ts
async function saveCalibration(result: DeviceCalibration) {
  const profile = sessionStore.getActiveProfile()!
  const existing = profile.deviceCalibrations.find(c => c.deviceMac === result.deviceMac)

  if (existing) {
    // Confirmar sobreescritura
    const confirmed = await showConfirmDialog(
      `Ya existe una calibración para este sensor (${new Date(existing.calibratedAt).toLocaleDateString()}). ¿Sobreescribir?`
    )
    if (!confirmed) return
  }

  const updatedCalibrations = [
    ...profile.deviceCalibrations.filter(c => c.deviceMac !== result.deviceMac),
    result
  ]
  profileStore.updateProfile(profile.id, { deviceCalibrations: updatedCalibrations })
}
```

#### Detección de golpes durante calibración
El asistente se suscribe a `useSensorData` con threshold=0 durante los pasos de golpes. Importante: **no usar `impact.intensity`** (que depende del threshold del perfil, aún no válido). Usar directamente `impact.magnitude`.

## Escenarios de test

1. **Escenario**: Completar 5 golpes avanza la serie correctamente
   - **Given**: `step === 'light'`, `series.light.hits = [10, 12, 11]`
   - **When**: Se registran 2 golpes más (magnitudes 13 y 14)
   - **Then**: `series.light.hits.length === 5`, `series.light.completed === true`, botones "Repetir"/"Continuar" visibles

2. **Escenario**: Repetir serie vacía los hits previos
   - **Given**: `series.normal.hits = [20, 21, 22, 23, 24]`, `completed = true`
   - **When**: El usuario pulsa "Repetir"
   - **Then**: `series.normal.hits = []`, `completed = false`, vuelve a escuchar golpes

3. **Escenario**: Cancelar en paso 'normal' no modifica calibraciones del perfil
   - **Given**: Perfil con `deviceCalibrations = [{ deviceMac: 'AA:BB', threshold: 15 }]`
   - **When**: Usuario cancela el asistente en step 'normal'
   - **Then**: `profileStore.profiles` no cambia — la calibración 'AA:BB' sigue siendo threshold=15

4. **Escenario**: Sobreescribir calibración existente con confirmación
   - **Given**: Perfil con calibración para 'AA:BB' ya existente; usuario completa el asistente y acepta
   - **When**: `saveCalibration(newResult)` con confirmación positiva
   - **Then**: `profile.deviceCalibrations` tiene exactamente 1 entrada para 'AA:BB' con los nuevos valores

5. **Escenario**: Primera calibración se añade sin sobreescritura
   - **Given**: Perfil con `deviceCalibrations: []`
   - **When**: `saveCalibration(newResult)`
   - **Then**: No se muestra diálogo de confirmación; `profile.deviceCalibrations.length === 1`

6. **Escenario**: No se registran golpes entre series (cooldown)
   - **Given**: Se acaba de registrar un golpe (t=0)
   - **When**: Llega otro impacto a t=150ms (dentro del cooldown de 300ms)
   - **Then**: El segundo impacto no se añade a la serie

## Notas de implementación

- **Threshold=0 en calibración**: pasar `threshold: 0` al `useSensorData` durante el asistente. Esto capturará cualquier movimiento. Considerar filtrar ruido con un umbral mínimo muy bajo (~2.0) para no capturar vibraciones ambientales.
- **Visual feedback de golpes**: cada golpe registrado se muestra como una barra horizontal proporcional a su magnitud (max de los 5 golpes = 100% del ancho). Colores: light=verde, normal=naranja, heavy=rojo.
- **Mobile**: el asistente se presenta como un screen de stack (push encima del tab actual), no como modal, para tener más espacio vertical.
- **Desktop**: presentar como overlay/modal a pantalla completa sobre la pantalla de Perfiles.
- **Número de golpes configurable**: aunque la spec dice 5, la constante `CALIBRATION_HITS_PER_SERIES = 5` debe ser fácilmente modificable.
- **Sin dependencia de HT-001**: aunque HT-001 elimina el modo "teléfono como sensor", este asistente debe funcionar con cualquier sensor activo, sea físico o el teléfono.

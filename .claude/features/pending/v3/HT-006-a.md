## Descripción

Introduce el tipo `DeviceCalibration` que almacena los parámetros de calibración (threshold, sensitivity, muestras) específicos para un par Perfil-Sensor. `CalibrationProfile` pasa a tener un array `deviceCalibrations: DeviceCalibration[]`. Los valores `threshold` y `sensitivity` en el perfil se mantienen como fallback genérico. Incluye migración de datos existentes.

## Criterios de aceptación

- [ ] El tipo `DeviceCalibration` existe en `shared/types/index.ts`
- [ ] `CalibrationProfile` incluye el campo `deviceCalibrations: DeviceCalibration[]` (puede ser array vacío)
- [ ] Los valores `threshold` y `sensitivity` en `CalibrationProfile` se mantienen como fallback
- [ ] `CalibrationData` se mueve de `CalibrationProfile` a `DeviceCalibration` (en el perfil queda como `calibrationData?: CalibrationData` solo por retrocompatibilidad de lectura)
- [ ] `calibrationService` expone `getCalibrationForDevice(profile, deviceMac)` que devuelve la calibración específica del sensor o el fallback
- [ ] Al cargar perfiles desde disco, los perfiles sin `deviceCalibrations` se migran añadiendo `deviceCalibrations: []`
- [ ] `useSensorData` y `trainingService` usan `getCalibrationForDevice` en lugar de leer `profile.threshold`/`profile.sensitivity` directamente
- [ ] Los tests existentes siguen pasando

// shared/types/index.ts

export interface DeviceCalibration {

  threshold: number
  sensitivity: number

  calibratedAt: number               // timestamp ms
}

// CalibrationProfile — modificado
export interface CalibrationProfile {
  id: string
  name: string
  threshold: number                      // fallback genérico (se mantiene)
  sensitivity: number                    // fallback genérico (se mantiene)

### Lógica de negocio

#### `getCalibrationForDevice(profile, deviceMac)`

```ts
function getCalibrationForDevice(
  profile: CalibrationProfile,
  deviceMac: string
): { threshold: number; sensitivity: number } {
  const specific = profile.deviceCalibrations.find(c => c.deviceMac === deviceMac)
  if (specific) return { threshold: specific.threshold, sensitivity: specific.sensitivity }
  return { threshold: profile.threshold, sensitivity: profile.sensitivity }
}
```

#### Migración al cargar profiles.json
En el loader de perfiles (ipc-handlers.ts / storage.ts), tras parsear el JSON:

```ts
function migrateProfile(raw: any): CalibrationProfile {
  return {
    ...raw,
    deviceCalibrations: raw.deviceCalibrations ?? [],
    // calibrationData legacy se conserva tal cual si existe
  }
}
```

#### Actualización de `useSensorData`
Antes:
```ts
const threshold = profile.threshold
const sensitivity = profile.sensitivity
```
Después:
```ts
const { threshold, sensitivity } = calibrationService.getCalibrationForDevice(profile, deviceMac)
```
`deviceMac` llega como parámetro adicional a `useSensorData(profile, deviceMac, placement?)`.

#### `analyzeCalibrationSamples` — nuevo retorno
Actualmente devuelve `{ suggestedThreshold, suggestedSensitivity }`. Añadir overload que devuelve `DeviceCalibration`:

```ts
function buildDeviceCalibration(
  deviceMac: string,
  samples: CalibrationData['samples']
): DeviceCalibration {
  const { suggestedThreshold, suggestedSensitivity } = analyzeCalibrationSamples(
    samples.light, samples.normal, samples.heavy
  )
  return {
    deviceMac,
    threshold: suggestedThreshold,
    sensitivity: suggestedSensitivity,
    calibrationData: { calibratedAt: Date.now(), samples },
    calibratedAt: Date.now()
  }
}
```

## Escenarios de test

1. **Escenario**: `getCalibrationForDevice` devuelve calibración específica cuando existe
   - **Given**: Perfil con `deviceCalibrations: [{ deviceMac: 'AA:BB', threshold: 20, sensitivity: 30 }]` y fallback threshold=15, sensitivity=25
   - **When**: `getCalibrationForDevice(profile, 'AA:BB')`
   - **Then**: Devuelve `{ threshold: 20, sensitivity: 30 }`

2. **Escenario**: `getCalibrationForDevice` usa fallback cuando no hay calibración para ese sensor
   - **Given**: Mismo perfil anterior
   - **When**: `getCalibrationForDevice(profile, 'CC:DD')` (sensor sin calibración específica)
   - **Then**: Devuelve `{ threshold: 15, sensitivity: 25 }`

3. **Escenario**: Migración de perfil antiguo sin `deviceCalibrations`
   - **Given**: JSON de perfil antiguo sin campo `deviceCalibrations`
   - **When**: `migrateProfile(rawJson)`
   - **Then**: El perfil resultante tiene `deviceCalibrations: []`

4. **Escenario**: `buildDeviceCalibration` calcula valores correctos
   - **Given**: `samples.light = [10, 12]`, `samples.normal = [20, 22]`, `samples.heavy = [40, 42]`
   - **When**: `buildDeviceCalibration('AA:BB', samples)`
   - **Then**: `threshold ≈ lightAvg * 0.8 ≈ 8.8`, `sensitivity ≈ 100 / (heavyAvg - lightAvg) ≈ 3.33`, `deviceMac === 'AA:BB'`

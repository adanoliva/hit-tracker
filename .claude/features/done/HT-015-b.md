## Descripción

Componente UI que guía al usuario a través de una `Routine` (o lista de ejercicios) paso a paso. Muestra el ejercicio activo, gestiona un timer de cuenta atrás (para ejercicios de tiempo) o un contador de reps, maneja el descanso entre ejercicios/series, y llama a un callback `onComplete` cuando termina todos los ejercicios. Es reutilizable: HT-015-c lo usa como fase previa a la sesión de boxeo.

## Criterios de aceptación

- [ ] Muestra nombre, descripción y músculos del ejercicio activo
- [ ] Para ejercicios de tiempo (`duration`): cuenta atrás en segundos, avanza automáticamente al terminar
- [ ] Para ejercicios de reps (`reps`): muestra "X reps" y un botón "Hecho" para avanzar manualmente
- [ ] Para ejercicios con `sets > 1`: muestra "Serie X / N", repite el timer/reps N veces con descanso entre series
- [ ] Descanso entre ejercicios/series: cuenta atrás del campo `rest` con opción de saltar
- [ ] Botón "Saltar" disponible en todo momento (salta el ejercicio/serie actual, no el descanso — el descanso tiene su propio "Saltar")
- [ ] Barra de progreso global: `ejercicio actual / total ejercicios` en la rutina
- [ ] Callback `onComplete(skipped: string[])` se llama al terminar el último ejercicio
- [ ] Callback `onAbort()` se llama si el usuario cancela la sesión completa
- [ ] Funciona en Desktop (React/Tailwind) y Mobile (React Native/StyleSheet)

### Lógica de negocio

**Hook `useWorkoutPlayer(routine)`** gestiona toda la lógica; el componente solo renderiza:

```
Estado interno:
  exerciseIndex: number          // índice en resolvedExercises (0-based)
  setIndex: number               // serie actual (0-based, 0 si sets=1)
  phase: 'exercise' | 'rest'
  timeLeft: number               // segundos restantes (para timer)
  skipped: string[]              // exerciseIds saltados
```

**Flujo de un ejercicio con sets:**

```
Para cada ejercicio en resolvedExercises:
  Para cada serie (1..sets):
    phase = 'exercise'
    Si duration: countdown desde duration → al llegar a 0 → phase = 'rest' (rest segundos) → siguiente serie
    Si reps: mostrar reps + botón Hecho → al pulsar → phase = 'rest' (rest segundos) → siguiente serie
    [última serie: después del rest, pasar al siguiente ejercicio]
Al terminar todos → onComplete(skipped)
```

**Reglas de sets/duration/reps:**
- El valor de `sets`, `reps`, `duration` en `RoutineExercise` tiene precedencia sobre los del `Exercise` base.
- Si `sets` es undefined, tratar como `sets = 1`.
- Si el ejercicio tiene `duration` Y `reps`, usar `duration` (prioridad del timer).

**Botón "Saltar":**
- Durante `phase = 'exercise'`: salta la serie/ejercicio completo. El `exerciseId` se añade a `skipped[]`. Pasa directamente al siguiente ejercicio (sin phase de rest).
- Durante `phase = 'rest'`: salta el descanso, inicia inmediatamente el siguiente ejercicio/serie.

**Timer:**
- Se implementa con `setInterval` de 1s dentro del hook.
- El intervalo se limpia en cleanup del useEffect.
- Si el componente se desmonta durante el timer, no llama callbacks.

## Escenarios de test

1. **Escenario**: Ejercicio de tiempo avanza automáticamente
   - **Given**: rutina con un ejercicio `{ duration: 2, rest: 1, sets: 1 }`
   - **When**: hook inicializado, avanza el tiempo (mock timer)
   - **Then**: a los 2s pasa a phase='rest'; a los 3s llama `onComplete([])`

2. **Escenario**: Ejercicio de reps requiere confirmación manual
   - **Given**: ejercicio `{ reps: 10, rest: 5, sets: 1 }`
   - **When**: hook inicializado
   - **Then**: phase='exercise', `timeLeft` es undefined/null; al llamar `advance()` pasa a phase='rest'

3. **Escenario**: Sets múltiples repiten el ciclo
   - **Given**: ejercicio `{ duration: 2, rest: 1, sets: 3 }`
   - **When**: timer avanza
   - **Then**: cicla exercise→rest 3 veces antes de pasar al siguiente ejercicio

4. **Escenario (borde)**: Saltar todos los ejercicios
   - **Given**: rutina con 3 ejercicios
   - **When**: `skip()` llamado 3 veces consecutivas
   - **Then**: `onComplete` recibe los 3 exerciseIds en `skipped[]`

5. **Escenario (borde)**: Rutina vacía
   - **Given**: `resolvedExercises = []`
   - **When**: hook inicializado
   - **Then**: `onComplete([])` se llama inmediatamente

## Notas de implementación

- El hook `useWorkoutPlayer` es idéntico en lógica entre Desktop y Mobile — considerar extraerlo a `shared/hooks/useWorkoutPlayer.ts` si el patrón de imports lo permite. Si no, duplicar (es ~60 líneas).
- No hay audio en esta fase (HT-015-c puede añadir un beep de transición si quiere, usando `audioService` ya existente).
- La imagen del ejercicio (`imageUrl`) se muestra si existe; si no, un placeholder con el icono de la categoría (Lucide). No bloquear el flujo si no hay imagen.
- Desktop: layout con panel izquierdo (info ejercicio) y panel derecho (timer/progreso).
- Mobile: layout vertical — imagen/icono arriba, info a continuación, timer grande, botones abajo.

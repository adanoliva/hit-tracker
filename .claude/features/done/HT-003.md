## Descripción

Permite al usuario compartir una sesión de entrenamiento directamente desde mobile usando el share sheet nativo de Android. El share incluye un mensaje de texto con las stats de la sesión y una imagen PNG capturada del gráfico de golpes. Disponible desde la pantalla de detalle (HT-002) y desde la pantalla de resultados post-entrenamiento.

## Criterios de aceptación

- [x] Existe un botón "Compartir" (icono `Share2` de Lucide) en la pantalla de detalle de sesión (`SessionDetail`)
- [x] Existe un botón "Compartir" en la pantalla de resultados post-entrenamiento (`TrainingResults`)
- [x] Al pulsar, se captura el gráfico del round actualmente seleccionado como imagen PNG
- [x] Se abre el share sheet nativo de Android con la imagen y el texto generado
- [x] El texto generado sigue la plantilla definida en lógica de negocio
- [x] Si la captura de imagen falla, el share se lanza igualmente solo con el texto (fallback)
- [x] Durante la captura (proceso asíncrono) el botón muestra un estado de carga y no se puede pulsar dos veces
- [x] El botón de compartir no bloquea la UI principal mientras captura

interface UseShareSessionOptions {

### Lógica de negocio

#### Texto generado (`mobile/src/utils/shareText.ts`)

```ts
function generateShareText(training: Training): string
```

Plantilla:
```
¡Vaya sesión! {X} min y una media de {Y} HPM. ¡A tope! 💪
#hittracker #boxing #training
```

Donde:
- `X` = duración total de la sesión en minutos, calculada como:
  ```ts
  const totalMs = training.rounds.reduce((acc, r) => acc + r.stats.duration, 0)
  const minutes = Math.round(totalMs / 60000)
  ```
- `Y` = `Math.round(training.hpmAverage)`

Si `minutes === 0` (sesión muy corta), usar `"< 1 min"` en lugar de `"0 min"`.

#### Hook `useShareSession`

```ts
export function useShareSession({ training, chartRef }: UseShareSessionOptions): UseShareSessionReturn
```

Flujo al llamar `share()`:

1. Setear `isSharing = true`
2. Generar `text = generateShareText(training)`
3. Intentar captura:
   ```ts
   const uri = await captureRef(chartRef, { format: 'png', quality: 0.9 })
   ```
4a. Si captura exitosa → llamar `expo-sharing` para compartir imagen+texto:
   ```ts
   await Sharing.shareAsync(uri, {
     mimeType: 'image/png',
     dialogTitle: 'Compartir sesión',
     UTI: 'public.png',
   })
   // Nota: expo-sharing no permite texto+imagen simultáneamente.
   // Alternativa: usar React Native's Share.share({ message: text }) si la red social no soporta imagen.
   // Estrategia: intentar primero con imagen vía Sharing.shareAsync; si falla, fallback a Share.share({ message: text })
   ```
   
   **Nota técnica importante**: `expo-sharing` abre el share sheet con la imagen; el texto se incluye como título o en el mensaje según la app destino. Para máxima compatibilidad, guardar la imagen en caché temporal (`FileSystem.cacheDirectory + 'hit-tracker-share.png'`) antes de llamar a `shareAsync`.

4b. Si captura falla (catch) → fallback:
   ```ts
   await Share.share({ message: text })  // React Native's built-in Share
   ```
5. Setear `isSharing = false` (en finally)

#### Ref al gráfico

En `SessionDetail`, el componente SVG del gráfico debe estar envuelto en una `<View ref={chartRef}>`. El hook recibe este ref. No modificar la lógica del gráfico, solo añadir el ref al wrapper.

En `TrainingResults`, capturar la sección de "Por ronda" completa o el gráfico del round 1 si existe. Si no hay gráfico en TrainingResults (la pantalla actual no lo tiene), capturar el bloque de stats globales como imagen alternativa.

## Escenarios de test

1. **Escenario**: Generación de texto con sesión normal
   - **Given**: Un `Training` con `hpmAverage = 45.7` y rounds con duración total de `125000` ms (≈ 2 min)
   - **When**: Se llama `generateShareText(training)`
   - **Then**: El resultado es `"¡Vaya sesión! 2 min y una media de 46 HPM. ¡A tope! 💪\n#hittracker #boxing #training"`

2. **Escenario**: Sesión de menos de 1 minuto
   - **Given**: Un `Training` con rounds cuya duración total es `45000` ms (45 segundos)
   - **When**: Se llama `generateShareText(training)`
   - **Then**: El texto incluye `"< 1 min"` en lugar de `"0 min"`

3. **Escenario**: Fallback a texto cuando la captura falla
   - **Given**: `captureRef` lanza una excepción
   - **When**: Se llama `share()`
   - **Then**: Se llama `Share.share({ message: text })` con el texto generado, y `isSharing` vuelve a `false`

4. **Escenario**: No se puede pulsar el botón dos veces
   - **Given**: `isSharing === true` (captura en curso)
   - **When**: El usuario intenta pulsar el botón Compartir de nuevo
   - **Then**: El botón está deshabilitado y no lanza una segunda captura

5. **Escenario**: HPM con decimales se redondea en el texto
   - **Given**: `training.hpmAverage = 38.49`
   - **When**: Se llama `generateShareText(training)`
   - **Then**: El texto muestra `"38 HPM"` (Math.round)

## Notas de implementación

- **Nuevas dependencias a instalar**:
  - `react-native-view-shot` — captura de View como imagen
  - `expo-sharing` — abre share sheet nativo con archivo
- **Permisos Android**: `expo-sharing` y `react-native-view-shot` no requieren permisos adicionales en el manifest para compartir (solo para guardar en galería, que no hacemos).
- **Imagen temporal**: guardar en `FileSystem.cacheDirectory` para no contaminar el almacenamiento del usuario. El archivo se sobreescribe en cada compartición (nombre fijo `hit-tracker-share.png`).
- **Emoji en el texto**: el emoji 💪 está en la plantilla. Verificar que se renderiza correctamente en el share sheet de Android.
- **TrainingResults sin gráfico propio**: si al implementar se decide que capturar el bloque de stats es suficiente, es válido. La imagen no tiene que ser necesariamente el scatter chart.
- **No añadir lógica de analytics** ni tracking de shares — fuera del scope de esta feature.

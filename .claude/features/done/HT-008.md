## Descripción

Actualmente el `powerMax` existe por sesión y por ronda, pero no hay un indicador de "forma actual" del usuario que persista entre sesiones. Esta feature añade `getUserPowerMax()` al `trainingStore` (desktop y mobile): calcula la media aritmética del `powerMax` de las últimas 5 sesiones del perfil activo y lo muestra en el Dashboard como "Tu power" junto a los datos existentes.

## Criterios de aceptación

- [x] `trainingStore` expone `getUserPowerMax(profileId: string): number` que devuelve la media aritmética del `powerMax` de las últimas 5 sesiones del perfil dado (0 si no hay sesiones)
- [x] Si hay menos de 5 sesiones, calcula la media con las disponibles
- [x] El Dashboard (desktop) muestra el valor junto al perfil activo
- [x] El Dashboard (mobile) muestra el mismo valor
- [x] El valor se recalcula automáticamente cuando se añade o elimina una sesión
- [x] Si no hay sesiones, muestra "—" en lugar de 0

### Tipos nuevos o modificados

No se requieren tipos nuevos. Se extiende la interfaz `TrainingState` existente:

```ts
interface TrainingState {
  // ... existente ...
  getUserPowerMax: (profileId: string) => number
}
```

### Lógica de negocio

**`getUserPowerMax(profileId)`**:

```ts
getUserPowerMax: (profileId: string): number => {
  const { trainings } = get()
  const sessions = trainings
    .filter((t) => t.profile?.id === profileId)
    .slice(0, 5)
  if (sessions.length === 0) return 0
  return Math.round(sessions.reduce((sum, t) => sum + t.powerMax, 0) / sessions.length)
}
```

`trainings` ya está ordenado de más reciente a más antiguo (el `addTraining` hace `[training, ...state.trainings]`), por lo que `.slice(0, 5)` devuelve las 5 últimas sin necesidad de ordenar.

**En el Dashboard**, el valor se obtiene así:

```ts
const getUserPowerMax = useTrainingStore((s) => s.getUserPowerMax)
const userPower = getUserPowerMax(profile.id)
```

Y se muestra en la tarjeta de perfil activo:

```
Perfil activo
[nombre del perfil]
Tu power: 87        ← nuevo, o "—" si userPower === 0
```

## Escenarios de test

1. **Media de 5 sesiones**
   - **Given**: 7 sesiones del perfil activo con powerMax [60, 70, 80, 90, 100, 50, 40] (orden reciente → antiguo)
   - **When**: `getUserPowerMax(profileId)`
   - **Then**: devuelve `Math.round((60+70+80+90+100)/5)` = `80`

2. **Menos de 5 sesiones**
   - **Given**: 3 sesiones con powerMax [50, 60, 70]
   - **When**: `getUserPowerMax(profileId)`
   - **Then**: devuelve `Math.round((50+60+70)/3)` = `60`

3. **Sin sesiones**
   - **Given**: 0 sesiones del perfil
   - **When**: `getUserPowerMax(profileId)`
   - **Then**: devuelve `0`

4. **Perfil diferente no contamina el resultado**
   - **Given**: 3 sesiones del perfil A con powerMax [80, 90, 100] y 5 sesiones del perfil B con powerMax [10, 20, 30, 40, 50]
   - **When**: `getUserPowerMax(profileIdA)`
   - **Then**: devuelve `Math.round((80+90+100)/3)` = `90` (ignora sesiones del perfil B)

5. **Borde: powerMax = 0 en alguna sesión**
   - **Given**: 2 sesiones con powerMax [0, 100]
   - **When**: `getUserPowerMax(profileId)`
   - **Then**: devuelve `50` (la sesión con 0 cuenta en la media)

- No añadir un campo persistido: el valor se deriva de `trainings` en tiempo de ejecución. Reactividad garantizada por Zustand.

- La tarjeta de "Perfil activo" en el Dashboard desktop está en `index.tsx` línea ~120. Añadir el valor debajo del nombre del perfil.

## Descripción

Elimina completamente el modo Game (arcade) de la aplicación: el tab de navegación, el componente, el store y los tipos asociados. La feature se archiva; el código se borra.

## Criterios de aceptación

- [x] El tab "Game" desaparece de la navegación (MobileLayout + TabletLayout)
- [x] `src/components/Game/` eliminado
- [x] Tipos `GameScore`, `GameTopThree` eliminados de `shared/types/index.ts`
- [x] Store de Game eliminado (si existe como archivo separado)
- [x] La app arranca sin errores y los otros tabs funcionan normalmente
- [x] No quedan imports muertos referenciando Game

## Requisitos técnicos

### Archivos a eliminar

- `src/components/Game/index.tsx` — componente principal
- `src/core/stores/gameStore.ts` — store (si existe como archivo)

### Archivos a modificar

- `shared/types/index.ts` — eliminar `GameScore`, `GameTopThree`
- `src/navigation/MobileLayout.tsx` — eliminar tab Game
- `src/navigation/TabletLayout.tsx` — eliminar tab Game (si aplica)
- Cualquier import de `GameScore`/`GameTopThree` en otros archivos

### Dependencias entre features

Ninguna. Se puede hacer primero o en paralelo con HT-017.

## Notas de implementación

- Verificar con grep que no quedan referencias a `GameScore`, `gameStore`, `GameTopThree` tras la limpieza.
- El store de Game puede estar embebido en otro store; en ese caso solo eliminar las claves y reducers de Game.

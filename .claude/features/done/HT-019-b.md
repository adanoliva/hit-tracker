## Descripción

Pantalla para crear y editar un `WorkoutPlan`. El usuario elige un nombre, selecciona ejercicios de calentamiento y core/fullbody del catálogo local, y configura la fase de boxing (duración, rounds, descanso). Los combos por round se configuran en HT-019-c (integrado como sub-sección del builder).

## Criterios de aceptación

- [ ] Campo de nombre del plan (obligatorio, máx. 40 chars)
- [ ] Sección "Calentamiento": lista de ejercicios del catálogo (`category: warmup`) con checkbox/toggle para incluirlos; muestra nombre, duración y músculos de cada uno
- [ ] Sección "Core / Fullbody": igual con `category: core | fullbody`
- [ ] Sección "Boxing": configuración de rounds (mismos controles que TrainingSetup actual: duración, nº rounds, descanso, modo libre)
- [ ] Sub-sección "Combos por round" (expandible): lista de rounds con campo de texto para combo de cada uno (HT-019-c)
- [ ] Botón "Guardar" activo solo si el nombre no está vacío
- [ ] Al guardar, llama `workoutPlanStore.addPlan()` y vuelve a la lista
- [ ] En modo edición, carga el plan existente y llama `workoutPlanStore.updatePlan()`
- [ ] Los ejercicios del catálogo se muestran ordenados: primero los seleccionados, luego los disponibles

## Requisitos técnicos

### Archivos a crear

- `src/components/Entrenamiento/PlanBuilder.tsx` — pantalla principal del builder
- `src/components/Entrenamiento/ExerciseSelector.tsx` — lista de ejercicios con checkbox por categoría
- `src/components/Entrenamiento/BoxingConfigSection.tsx` — sección boxing (reutiliza lógica de TrainingSetup)

### Props de PlanBuilder

```ts
interface PlanBuilderProps {
  existingPlan?: WorkoutPlan  // si se pasa, es modo edición
  onSave: () => void
  onCancel: () => void
}
```

### ExerciseSelector

```ts
interface ExerciseSelectorProps {
  category: ExerciseCategory | ExerciseCategory[]
  selected: string[]  // exerciseIds seleccionados
  onChange: (ids: string[]) => void
}
```

Muestra ejercicios del catálogo filtrados por categoría. Cada fila: nombre, duración o reps, músculos. Checkbox a la derecha. Los seleccionados aparecen al inicio.

### BoxingConfigSection

Extrae los controles de rounds de `TrainingSetup` como componente reutilizable:
- Duración por ronda (opciones fijas)
- Número de rounds
- Descanso entre rounds
- Toggle modo libre

Recibe `value: BoxingPhaseConfig` y `onChange`.

### Estado del builder

```ts
{
  name: string
  warmupIds: string[]
  coreIds: string[]
  boxing: BoxingPhaseConfig  // roundScripts se editan en HT-019-c
}
```

## Notas de implementación

- El builder es un `ScrollView` con secciones colapsables para no saturar la pantalla.
- El orden de secciones: Nombre → Calentamiento → Core/Fullbody → Boxing (config) → Combos (expandible).
- Los combos (HT-019-c) son la sub-sección "Combos por round" dentro del builder, no una pantalla separada.
- Cuando `numRounds` cambia, los `roundScripts` se truncan o amplían para mantener coherencia (si había 5 rounds y se baja a 3, los scripts de round 4 y 5 se descartan).

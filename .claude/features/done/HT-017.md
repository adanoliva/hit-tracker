## Descripción

Reestructura la navegación principal: el tab actual "Entrenamiento" (Training) pasa a llamarse **"Sesión"** y mantiene exactamente su comportamiento actual. Se añade un nuevo tab **"Entrenamiento"** que será la entrada al sistema de planes de entrenamiento (implementado en HT-019). El tab "Game" ya habrá sido eliminado (HT-016).

## Criterios de aceptación

- [x] Tab que antes se llamaba "Training/Entrenamiento" ahora se llama "Sesión" con icono apropiado (`Timer` de Lucide)
- [x] Nuevo tab "Entrenamiento" con icono `ClipboardList` (o similar) que muestra un placeholder/pantalla vacía
- [x] El orden de tabs es: Dashboard | Sesión | Entrenamiento | Dispositivos | Perfiles
- [x] El comportamiento de "Sesión" es idéntico al anterior (sin regresión)
- [x] La navegación funciona en portrait y landscape (MobileLayout y TabletLayout)

## Requisitos técnicos

### Archivos a modificar

- `src/navigation/MobileLayout.tsx` — renombrar tab, añadir nuevo tab, reordenar
- `src/navigation/TabletLayout.tsx` — mismos cambios si aplica

### Archivos a crear

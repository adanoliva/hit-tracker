## Descripción

Rediseño completo del modo Game al estilo máquina recreativa de feria. El usuario pulsa "Empezar", la máquina espera un único golpe, mide su potencia real (`impact.magnitude`, valor raw entero) y comprueba si entra en el TOP 3 local. Si entra, se pide al usuario que introduzca sus iniciales (1–4 letras). Si no entra, pantalla de "LOSER". El TOP 3 se persiste en disco y nunca se puede resetear.

## Criterios de aceptación

- [ ] La pantalla principal del Game muestra el TOP 3 con posición, iniciales y puntuación
- [ ] Si el TOP 3 está vacío (primera vez), se muestran los 3 puestos como `--- · ---`
- [ ] Hay un botón "EMPEZAR" visible cuando no hay partida en curso
- [ ] Al pulsar "EMPEZAR" la UI entra en estado "esperando golpe": mensaje tipo "¡GOLPEA!" con animación de espera
- [ ] Hay un botón "Cancelar" disponible durante la espera para volver al estado inicial
- [ ] Solo se registra el primer golpe detectado (`isValid` o no — se acepta cualquier impacto)
- [ ] Tras detectar el golpe, se calcula la puntuación = `impact.magnitude` (valor raw entero, ej. 847)
- [ ] Si la puntuación entra en el TOP 3 (es mayor que al menos uno de los 3 scores actuales): mostrar pantalla "¡NUEVO RECORD!" con la puntuación y un input de iniciales
- [ ] El input de iniciales acepta entre 1 y 4 letras (solo caracteres alfabéticos A–Z, auto-uppercase)
- [ ] Confirmar iniciales guarda la entrada en el TOP 3, desplaza las posiciones inferiores y persiste en disco
- [ ] Si la puntuación NO entra en el TOP 3: mostrar pantalla "LOSER" con la puntuación obtenida y un botón para volver
- [ ] Pantalla de "LOSER" muestra también el mínimo necesario para entrar al TOP 3
- [ ] El TOP 3 persiste entre sesiones de la app (guardado en disco local)
- [ ] No existe botón de reset del TOP 3
- [ ] Requiere dispositivo conectado para jugar (mismo comportamiento que ahora)

### Lógica de negocio

#### Persistencia en disco
- **Desktop**: `app.getPath('userData')/HitTracker/game-scores.json` → array de hasta 3 `GameScore`
- **Mobile**: `{documentDirectory}/HitTracker/game-scores.json` → igual

Formato del archivo:
```json
[
  { "initials": "AAA", "score": 87, "date": 1718880000000 },
  { "initials": "BXK", "score": 72, "date": 1718800000000 },
  null
]
```

#### Máquina de estados de la partida

```
idle
  → [pulsar EMPEZAR] → waiting
  
waiting
  → [detectar golpe] → new-record (si score entra en top3) | loser (si no)
  → [cancelar]       → idle

new-record
  → [confirmar iniciales] → idle  (TOP 3 actualizado y guardado)

loser
  → [pulsar "Volver"] → idle
```

#### ¿Cuándo entra en TOP 3?
```ts
function entersTopThree(score: number, top: GameTopThree): boolean {
  // Entra si alguna posición es null o si supera la puntuación más baja
  const scores = top.filter(Boolean).map(e => e!.score)
  if (scores.length < 3) return true           // hay hueco libre
  return score > Math.min(...scores)
}
```

#### Insertar en TOP 3
```ts
function insertScore(entry: GameScore, top: GameTopThree): GameTopThree {
  const current = top.filter(Boolean) as GameScore[]
  const updated = [...current, entry]
    .sort((a, b) => b.score - a.score)  // mayor primero
    .slice(0, 3)
  return [updated[0] ?? null, updated[1] ?? null, updated[2] ?? null]
}
```

#### Detección del golpe en modo game
El hook `useSensorData` ya emite impactos. En el componente Game (o en `gameStore`), suscribirse a los impactos **solo cuando `phase === 'waiting'`**. Al recibir el primer impacto:

```ts
// En el componente Game, dentro de un useEffect:
if (phase === 'waiting' && newImpact) {
  gameStore.registerHit(newImpact.magnitude)
}
```

`registerHit()` en el store:
```ts
registerHit(magnitude: number) {
  set({ lastScore: magnitude, pendingScore: magnitude })
  if (entersTopThree(magnitude, get().topThree)) {
    set({ phase: 'new-record' })
  } else {
    set({ phase: 'loser' })
  }
}
```

#### Input de iniciales
- Solo acepta A–Z (filtrar otros caracteres en `onChange`/`onChangeText`)
- Auto-uppercase al teclear
- Longitud mínima 1, máxima 4
- En desktop: input de texto con foco automático al entrar en fase `new-record`
- En mobile: `TextInput` con `autoCapitalize="characters"`, `maxLength={4}`, `keyboardType="default"`
- El botón de confirmar está deshabilitado si `initials.length === 0`

#### Pantalla LOSER — mínimo para entrar al TOP 3
```ts
function minScoreForTop3(top: GameTopThree): number {
  const filled = top.filter(Boolean) as GameScore[]
  if (filled.length < 3) return 0   // hay hueco, cualquier score entra
  return Math.min(...filled.map(e => e.score)) + 1
}
```
Mostrar: `"Necesitabas al menos ${minScoreForTop3(topThree)} para entrar"`

## Escenarios de test

1. **Escenario**: Score entra en TOP 3 con hueco libre
   - **Given**: `topThree = [{ initials:'AAA', score:90 }, null, null]`
   - **When**: `entersTopThree(50, topThree)`
   - **Then**: Devuelve `true` (hay huecos libres)

2. **Escenario**: Score NO supera el mínimo del TOP 3 lleno
   - **Given**: `topThree = [{ score:90 }, { score:80 }, { score:70 }]`
   - **When**: `entersTopThree(65, topThree)`
   - **Then**: Devuelve `false`

3. **Escenario**: Score igual al mínimo no entra (debe ser estrictamente mayor)
   - **Given**: `topThree = [{ score:90 }, { score:80 }, { score:70 }]`
   - **When**: `entersTopThree(70, topThree)`
   - **Then**: Devuelve `false`

4. **Escenario**: Insertar score desplaza al último
   - **Given**: `topThree = [{ initials:'AAA', score:90 }, { initials:'BBB', score:80 }, { initials:'CCC', score:70 }]`
   - **When**: `insertScore({ initials:'DDD', score:85 }, topThree)`
   - **Then**: Resultado = `[{ initials:'AAA', score:90 }, { initials:'DDD', score:85 }, { initials:'BBB', score:80 }]` (CCC desaparece)

5. **Escenario**: Mínimo para entrar con TOP 3 lleno
   - **Given**: `topThree = [{ score:90 }, { score:80 }, { score:70 }]`
   - **When**: `minScoreForTop3(topThree)`
   - **Then**: Devuelve `71`

6. **Escenario**: Cancelar durante espera vuelve a idle
   - **Given**: `phase === 'waiting'`
   - **When**: `gameStore.cancelGame()`
   - **Then**: `phase === 'idle'`, `lastScore === null`

## Notas de implementación

- **Animación "¡GOLPEA!"**: usar un pulso/parpadeo en el texto o un círculo animado al estilo "ready" de máquina recreativa. En desktop: CSS `@keyframes pulse`. En mobile: `Animated.loop` con scale.
- **Pantalla LOSER**: texto grande en rojo/naranja con la puntuación obtenida. Puede incluir un efecto de "shake" corto (50ms vibración). En mobile, `Vibration.vibrate(200)` de React Native.
- **Pantalla NUEVO RECORD**: texto grande dorado/amarillo parpadeante. En mobile, `Vibration.vibrate([0, 100, 50, 100])`.
- **Flash de récord**: mantener la animación flash existente (accent color) como transición antes de mostrar el input de iniciales.
- **`useSensorData` en Game**: el componente ya recibe impactos del sensor. Solo hay que añadir la lógica de escucha condicional según `phase`. No modificar `useSensorData`.
- **TOP 3 vacío inicial**: al cargar `game-scores.json` si no existe el archivo, inicializar `topThree` como `[null, null, null]`.
- **Posición en TOP 3 con empate de score**: si el nuevo score es igual a uno existente, igual entra (orden: el nuevo va por debajo del existente con mismo score). Esto está cubierto por `sort` estable + `> Math.min`.
- **Tablet (mobile)**: el `TabletLayout.tsx` actualmente no tiene tab de Game. Esta feature no lo añade — fuera de scope.

## Descripción

Sub-sección del builder (HT-019-b) que permite al usuario definir la secuencia de golpes (combo) para cada round del plan de boxing. El input es texto libre con notación de boxeo (1=jab, 2=cross, 3=gancho izq, etc.). Durante la sesión, este texto se muestra como guía estática en la pantalla de round (HT-020).

## Criterios de aceptación

- [ ] Sección "Combos por round" expandible dentro del builder, visible solo cuando `numRounds > 0` (no aplica a modo libre)
- [ ] Una fila por round ("Round 1", "Round 2"…) con campo de texto libre para el combo
- [ ] El campo acepta notación libre: `1-2-3-Slip Iz-3b-6`, `1b-1-2-Step-2-3-2`, etc.
- [ ] Campo opcional — se puede dejar vacío (la sesión simplemente no muestra combo ese round)
- [ ] Límite de 120 caracteres por combo
- [ ] Referencia de notación visible cerca del campo: panel pequeño desplegable con tabla de golpes
- [ ] Al cambiar `numRounds` en el builder, la lista de combos se sincroniza (añade filas o trunca)
- [ ] Los valores se guardan en `boxing.roundScripts` del `WorkoutPlan`

### Notación de referencia (tabla de golpes)

| Código | Golpe |
|--------|-------|
| 1 | Jab |
| 2 | Cross |
| 3 | Gancho izquierdo |
| 4 | Gancho derecho |
| 5 | Uppercut izquierdo |
| 6 | Uppercut derecho |
| b | Golpe al cuerpo (sufijo: 3b = gancho izq al cuerpo) |
| Slip Iz / Slip Der | Esquiva lateral |
| Step | Paso de salida |
| Duck | Agachada |
| Pivot | Giro de salida |

Esta tabla se muestra en un panel colapsable "Ver referencia de golpes" junto al editor.

### RoundComboEditor Props

```ts
interface RoundComboEditorProps {
  numRounds: number
  scripts: BoxingRoundScript[]
  onChange: (scripts: BoxingRoundScript[]) => void
}
```

### Lógica interna

El componente mantiene un array de `{ round, combo, note? }`. Cuando `numRounds` cambia:
- Si sube: añade entradas vacías para los rounds nuevos
- Si baja: trunca las que superen `numRounds`

`onChange` se llama en cada cambio de texto (con debounce de 300ms si hay muchos rounds).

## Notas de implementación

- Notación libre a propósito: no hay validación de golpes, el entrenador escribe como quiera.
- El campo `note` (opcional) puede usarse para instrucciones extra ("Entra con jab doble, busca el cuerpo").
- Mobile: cada fila de round usa `TextInput` multiline (máx 2 líneas visibles) con label a la izquierda.
- La referencia de golpes se renderiza como `Modal` o panel en acordeón para no ocupar espacio permanente.
